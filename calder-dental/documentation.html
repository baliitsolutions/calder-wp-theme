Calder — Dental Clinic Landing Page

Thank you for your purchase. This guide covers everything you need to put the template online with your own content. No build tools are required: open index.html in a browser and you're running.

Change colours and fonts

Open assets/css/style.css and edit the variables in :root. Every colour on the page comes from these.

:root {
  --pine: #0f3b34;      /* main dark colour */
  --mint: #dcefe8;      /* tinted sections */
  --mint-deep: #7cc6ad; /* accents */
  --gum: #f2b8bd;       /* secondary accent */
}

To change fonts, replace the Google Fonts <link> in index.html and update --font-display and --font-body.

Edit text, prices and contact details

All content is plain HTML in index.html, grouped by commented sections (HEADER, HERO, TREATMENTS and so on). Search for these and replace them with your own:

  • Clinic name: Calder Dental Studio
  • Phone: (555) 014-2200 and tel:+15550142200
  • Email: hello@example.com
  • Address: 48 Harbour Road

To add a treatment, copy one <li> inside <ul class="treatments">. To remove a section, delete its whole <section> and its link in the menu.

Set your opening hours

Edit OPENING_HOURS at the top of assets/js/main.js. Use 24-hour times, and null for closed days. The hours table and the "Open now / Closed now" card update automatically from this one list.

const OPENING_HOURS = {
  1: ["08:00", "18:00"], // Monday
  ...
  0: null                // Sunday (closed)
};

Add team photos

Each team photo is a placeholder showing initials. Add a style attribute pointing to your image and the initials disappear:

<div class="photo" data-initials="MO"
     style="background-image:url('assets/img/maya.jpg')"
     role="img" aria-label="Photo of Dr. Maya Okafor"></div>

Portrait images around 800 × 1000 px work best.

Receive booking requests

Out of the box the form validates and shows a confirmation, but does not send anything. To receive requests by email, sign up for a form service such as Formspree, Getform or Netlify Forms and add its URL as the form's action:

<form class="book-form" novalidate data-book-form
      action="https://formspree.io/f/your-id" method="POST">

Once an action is set, the script lets valid submissions go through to that service.

Testimonials

The quotes in "From our patients" are sample text. Replace them with real reviews from your patients, with their permission, before publishing.

Publish

Upload the whole folder to any static host: Netlify, Vercel, GitHub Pages, Cloudflare Pages, or the public_html folder of regular web hosting.

Browser support

Current versions of Chrome, Edge, Firefox and Safari, on desktop and mobile. The page respects the visitor's reduced-motion setting and is keyboard accessible.

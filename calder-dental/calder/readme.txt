A calm, modern block theme for dental clinics and healthcare practices.

== Description ==

Calder is a full site editing (block) theme. Every section of the home page is made of ordinary WordPress blocks, so you can change text, prices, photos and colours in Appearance → Editor without code or page-builder plugins.

Included:
* Home page with hero, treatments price list, first-visit steps, team, membership plan, reviews, FAQ and contact sections
* Each section is also available as a pattern under "Calder sections" in the block inserter
* Block styles: Card (group), Checklist and Steps (list), Price list and Opening hours (table)
* Three colour styles: Pine & Mint (default), Navy & Peach, Plum & Honey
* Templates for pages, posts, blog index and 404, plus a "Page without title" template

== Installation ==

1. In your WordPress dashboard go to Appearance → Themes → Add New Theme → Upload Theme.
2. Choose calder.zip and click Install Now, then Activate.
3. Go to Appearance → Editor to edit the home page, header and footer.
